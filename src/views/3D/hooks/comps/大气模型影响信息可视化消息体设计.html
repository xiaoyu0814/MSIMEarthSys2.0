气象告警扩展数据结构设计文档（前端渲染专用）

1. 设计目标

  • 后端直接下发提示信息，前端不再硬编码匹配 action_type
  • 通过 weather_type 缩写判断前端渲染方法
  • 支持气象空间范围（经纬度高度盒）
  • 支持消息级别，用于前端不同可视化样式
  • 支持气象资源地址追溯

2. 气象类型枚举（英文缩写）

weather_type 可选值：
  • ICE = 积冰
  • TURB = 颠簸
  • WS = 风切变
  • VIS = 可见光
  • IR = 红外
  • AD = 大气波导

3. 消息级别枚举

  • INFO = 提示
  • WARN = 警告
  • ALARM = 告警
  • CRIT = 严重告警

5. 前端渲染逻辑（根据 weather_type 调用对应方法）

// 前端渲染判断逻辑
const weatherType = data.Data.motion_analysis.weather.type;

switch (weatherType) {
  case "ICE":
    renderIceRegion();    // 积冰
    break;
  case "TURB":
    renderTurbRegion();   // 颠簸
    break;
  case "WS":
    renderWindShear();    // 风切变
    break;
  case "VIS":
    renderVisibleImg();   // 可见光
    break;
  case "IR":
    renderInfraredImg();  // 红外
    break;
  case "AD":
    renderAtmDuct();      // 大气波导
    break;
  default:
    console.log("Unknown weather type");
}

6. 前端展示规则

  • 提示文字：msg.content
  • 可视化样式：msg.level
  • 气象区域：weather.region 下的经纬度高度范围
  • 渲染方式：由 weather.type 唯一决定

7. 设计亮点

  • 全英文缩写，适合前端项目
  • 无破坏性扩展，兼容老结构
  • 渲染路由完全由后端控制
  • 支持空间气象区域绘制
  • 支持告警消息、级别、资源追溯
